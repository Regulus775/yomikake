次の巻を選ぶ導線の検査

知りたいこと（読了パネルの「📂 次の巻を選ぶ」の設計に使う。設計書 design_series_next.md 予定）
(1) ファイル選択を前に開いた本と同じフォルダから開けるか（startIn にファイルのハンドルを渡す。PC・Android の Chrome）
(2) 1 回のタップで「クリップボードにシリーズ名を入れる」と「ファイル選択を開く」の両方が通るか（全環境）
(3) ファイル選択の検索欄に貼り付けて絞り込めるか（全環境・目視）

置き場所: https で開くこと（ファイル選択の API とクリップボードは https でしか動かない）。 https://www.ayati.com/book/tests/probe/next-volume-picker.html など。

手順
1. [0] で、シリーズ物の 1 冊（例: RAIL WARS! 2）を選ぶ。これが「いま読んでいる本」の代わり。
2. [A]〜[G] を順に押し、それぞれの下の観察ボタンで見えたことを記録する（ファイル選択は選ばずに閉じてもよい）。
3. [B] はページを再読み込みしてから押す（実際の yomikake では前回の起動で保存したハンドルを使うため）。
4. 最後に「ログをコピー」して持ち帰る。ファイル名以外の中身は読まない。

シリーズ名（クリップボードに入れる文字）

ファイル名に含まれる短い語にする（例: RAIL）。全角／半角の違いで当たらないことがあるので、それも見る。

(2)(3) 1 回のタップでクリップボード＋ファイル選択

本命。yomikake ではこの形にしたい。開いたファイル選択の検索欄に貼り付けて、絞り込めるかを見る。

書き込みの完了を待ってから開く。待つ間にタップの効力が切れて、ファイル選択が開かないかもしれない。

タップから時間が経っても書き込めるか（通るなら、ファイル選択を先に開く形でもよい）。
