AozoraEpub3 の CSS の実測

何を測るか（設計書 design_aozoraepub3.md）
[A] AozoraEpub3 は縦中横を .tcy span { text-combine: horizontal }（＋ -webkit- / -epub-）という 古い書き方だけで書いている。今の標準の text-combine-upright が無い。どのブラウザで効くかを数字で見る。
[B]〜[D] AozoraEpub3 の CSS は字下げ・字上げ・傍線などを 縦書き前提の物理プロパティ（margin-top / border-right など）で書いている。yomikake の「横書き」モードで強制的に横組みにすると崩れる。補正の効き目を目で見る。
[E]〜[F] yomikake のダーク系テーマは html,body の文字色しか変えないので、ePub が色を指定した要素（リンク・罫囲み・前書き/後書き）が背景に沈む。

手順: このページを開き、[A] の表と [B]〜[F] の見た目を、PC Chrome・PC Firefox・Android Chrome・iPhone/iPad Safari で スクリーンショットに撮ってください。各ブロックの [A] などの札で見分けます。
